# 実験E　判定ルールを変える

実験Aのスライダーを初期値に戻し、Eを開きます。`コードを試す` を押す前に、`MIN_RSSI`（最も強いAPに必要な強さ）と `MIN_GAP`（上位2台を区別するための差）を現在の値と比べ、どんな判定になるか予想します。

1. まず見本のままで試し、結果を記録します。
2. `const MIN_RSSI = -72;` の `-72` を、予想に合わせて変更します。ほかの行をそのままにして `コードを試す` を押します。
3. `見本に戻す` で復元し、今度は `const MIN_GAP = 4;` の `4` だけを変えて比べます。
4. どの変更で推定を保留したか説明します。上位2台を区別しやすい別の入力を、実験Aで作って再確認します。

### HTMLのコピーで関数を編集する

1. エクスプローラーで `index.html` をコピーし、`lab-copy.html` など別名にします。拡張子は `.html` のままにします。
2. コピーをメモ帳などのテキストエディターで開きます。`実験E 編集ここから` を検索し、`function estimateExerciseArea` から閉じかっこ `}` までの約14行を見つけます。
3. `MIN_RSSI` または `MIN_GAP` の初期値を1か所変え、UTF-8で保存します。コピーしたHTMLをブラウザで開き、開いていた場合は再読み込みします。
4. Eのコード欄に変更した関数が表示されることを確かめ、同じ入力で `コードを試す` を押します。画面内で入力し直さなくても、ファイルの変更が結果に反映されるかを確認します。
5. 慣れてきたら、例えば `first.rssi < ...` の `<` を `<=` にします。入力が境界とちょうど同じときだけを試し、判定条件の違いを説明します。

`見本に戻す` は、開いているHTMLの関数をコード欄に戻します。ファイルを編集して元に戻す場合は最初の `index.html` を開くか、コピーの関数を [choose-area.js](../examples/choose-area.js) の見本と交換してください。見本の最初のコメントは説明用で、コピーする範囲は `function estimateExerciseArea` から閉じかっこ `}` までです。
