# Wi-Fi位置推定 実験ラボ

仮想の電波データを変えながら、PCのエリアをどう推定できるか考える教材です。データはすべて模擬値です。推定している対象は架空のPCで、実在する先生や学校の設備は扱いません。

## すぐに始める

1. ZIPで受け取った場合は、右クリックして「すべて展開」を選びます。展開済みのフォルダーなら、この手順は不要です。
2. このファイルと同じフォルダーにある `index.html` をダブルクリックします。EdgeやChromeなど、PCで使えるブラウザで開きます。
3. ラボが開いたら「実験A」でスライダーを1つ動かします。グラフと場所の推定が変わるか確かめます。
4. 教材と記録用紙は [印刷できる教材ページ](materials.html) を開きます。印刷する資料を選び、「印刷画面を開く」を押します。

アプリはPC内のHTMLだけで動きます。Python、Node.js、npm、管理者権限、インターネット接続の準備は不要です。ZIPの中から直接開くと別ファイルへのリンクが使えないことがあるので、先にフォルダー全体を展開します。実際の学校PCでの動作可否は、当日の端末ルールに従って事前確認してください。

## 生徒向け操作ガイド

どの実験でも、先に**予想を1文書く**、**1つだけ変える**、**結果を記録する**の順で進めます。何を試したかは [実験ワークシート](worksheets/EXPERIMENT.md) に記録できます。

|実験|最初にすること|確かめること|
|---|---|---|
|A 電波強度|AP A〜Dのスライダーを1つ動かす。戻すときは「初期値に戻す」|RSSIの大小と最強AP。僅差や同じ値のときはどうなるか|
|B 平均と中央値|1行に1つのRSSIを書き、「外れ値を1件追加」を試す|値の個数、平均と中央値、標準偏差。変える前後の差|
|C APの数|シナリオ・シードを決め、APのチェックを切り替える|ON/OFFで最後の観測に基づく推定が変わるか。「同じ条件でやり直す」はシナリオ・シードを保ち、APを全ONにする|
|D 方式の比較|Cと同じ入力で、最強AP・平均RSSI・簡易フィンガープリントを見比べる|3方式が見る観測、結果の違い、その理由|
|E プログラムを変える|2つの判定条件の片方だけ数値を変え、「コードを試す」|ルールと結果の関係。「見本に戻す」で比較をやり直せる|

**CとDで比べるとき**　シナリオは模擬場面、シードは同じ模擬データを作り直すための番号です。CとDは5回の模擬観測とAP設定を共有します。シードを入力し直したら「同じ条件でやり直す」を押して反映します。変更する前にシナリオ・使用中のシード・AP構成・模擬上の正解を書きます。ONのAP数と、最後の行で実際に値があるONのAP数は分けて記録します。Dの「初期値に戻す」は方式だけを最強APに戻します。

**記録を残すとき**　実験Cでは「実験前の予想」と「結果メモ」を書き、「条件と結果を記録」を押します。「記録CSVを保存」を選ぶか、CSV欄をコピーします。この記録はCの簡易フィンガープリント用です。Dの最強AP・平均RSSIやA・B・Eの結果はワークシートへ書きます。学校PCでダウンロードが制限される場合は、紙や許可されたローカルのテキストファイルへ転記してください。画面の記録はタブ内の一時状態なので、閉じる前に残します。

## 自分に合う進め方

- **初めての人**　教材1の図を見てAを操作します。Bで平均と中央値の片方を手計算で確かめ、気付いたことを記録します。Eは数値1つの変更から始めます。
- **実験に慣れている人**　CまたはDで、同じ複数シナリオを2条件ずつ試します。正解・誤表示・不明を分け、分母と一緒に報告します。
- **プログラム経験がある人**　Eの[発展演習](exercises/CHANGE_A_RULE.md)で境界値を設計し、複製したファイルで1か所を編集します。うまくいかなかった入力も再現できるように残します。
- **時間が短いとき**　Aで操作をつかみ、B・C・Dから班の疑問に合う実験を1つ選びます。Eは次回に回せます。

このラボは本体のPython位置推定エンジンと別の教材です。少数の仮想AP・部屋・測定値を使い、手順や仮説を見比べられるようにしています。模擬結果から実際の学校での精度は分かりません。

実施した動作確認と開発者向けの再確認方法は [確認記録](docs/VERIFICATION.md) にまとめています。
