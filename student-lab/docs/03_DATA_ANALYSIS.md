# 教材3　データ分析と誤差

**今日の問い**　1回だけ大きく外れた測定を入れると、データの見え方はどう変わるでしょうか。

## 平均と中央値

あるAPを静止したPCから5回測ったと仮定します。単位はdBmです。

|データ|小さい順に並べた値|平均|中央値|
|---|---|---:|---:|
|元の5個|−62、−61、−60、−59、−58|−60|−60|
|−90を1個追加|−90、−62、−61、−60、−59、−58|−65|−60.5|

**平均**は値の合計を個数で割ります。**中央値**は並べたときの真ん中の値で、偶数個なら中央2個の平均です。上の例は教材用の計算練習です。画面の初期値とは異なる場合があるので、実験Bでは画面の測定値を自分で書き取って確認します。

他と大きく違う値を**外れ値**と呼ぶことがあります。大きく外れた値に、機器の誤りや環境の変化など、意味がある場合もあります。消す前に「何を知るために、どういう基準で除くか」を決めます。

## ばらつきと測定回数

- **ノイズ**は、知りたい値に重なる意図しない変動です。信号を測る向き、人や物の動き、機器の揺らぎなどが値に影響することがあります。
- **分散**は、各測定値と平均の差を二乗し、その平均をとったものです。ここでは手元にある値全体の広がりを記述します。元の5個では平均との差が−2、−1、0、1、2なので、分散は (4＋1＋0＋1＋4)÷5＝2 です。
- **標準偏差**は分散の平方根です。この例では約1.41 dBです。大きいほど平均から離れた測定が多い傾向があります。場所を変えた複数エリアのデータを混ぜると、場所による差までばらつきに含まれます。
- **測定回数**を増やすと、たまたまのゆらぎの影響を抑えられる場合があります。同じ偏りが繰り返される場合や、似た条件の連続測定では、回数だけで偏りや依存関係は解消しません。

## 実験Bでグラフを読む

1. RSSIの測定値を書き取り、平均と中央値がどこに来るか予想します。
2. 測定値を1つ変更するか外れ値を加えます。変える前後で値の個数を記録してください。
3. 1回目から順番に追えるグラフでは、横軸が測定番号、縦軸がRSSIです。分布や棒グラフでは並び順の意味が違うので、まずラベルを見ます。
4. 平均と中央値がそれぞれ何dB動いたか書きます。表示上の丸めと計算の結果を分けて考えます。

**考える問い**　普段の静止PCの信号を知るときと、本当に環境が変わったことを早く知りたいときで、選びたい処理は同じですか。
