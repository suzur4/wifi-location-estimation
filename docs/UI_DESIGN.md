# 画面設計と操作仕様

この文書は`main`の画面構成と、変更時に維持する操作上の方針を説明する（2026-11-08確認）。主な画面デザインは2026-11-04に整えたもの。過去の画面写真と現在の自動テストの確認範囲は[検証記録](VERIFICATION.md)で区別している。

## 読みやすさの方針

名前、PCの推定エリア、測定時刻を短時間で探せる名簿形式を使う。学校での掲示とスマートフォンの両方を想定し、文字の大きさ、コントラスト、操作できる範囲を優先する。

- **色**：白地に濃い文字（`#1f2328`、コントラスト比15.8）。補足文は`#555d6b`（6.6）と`#6b7280`（4.8）。アクセントは青`#1558b0`（6.9）1色だけにして、リンク・選択中のメニュー・主なボタンに限る。
- **文字**：OS標準のゴシック体（ヒラギノ角ゴ、Noto Sans JP、游ゴシック、メイリオ）。本文16px、補足13〜14px、見出し20〜26px。字間の調整や明朝体は使わない。
- **状態**：推定できた先生は場所を太字で示し、左に小さな緑の点を付ける。「位置不明」「非公開」は灰色の通常の太さで、理由を1行で添える。色だけに頼らず、文字で状態が分かる。
- **文言**：注意書きは画面上部の「試作版」帯（架空データであること）と、見出し下の1文（PCの場所であり本人の居場所ではないこと）にまとめた。言い回しは「1分未満前」→「1分以内」、「画面取得」→「最終更新」、「所在情報は公開されていません」→「公開を停止しています」のように、普段の言葉にした。
- **入力**：入力欄は高さ48px、文字16px（スマートフォンで勝手に拡大されない大きさ）。ボタン・リンクは押せる範囲を44px以上にする。フォーカス位置は青い枠で必ず見えるようにする。

## 画面ごとの構成

**先生をさがす**：「名前・よみがな」と「教科」で絞り込む。名前は空白・全角/半角・ひらがな/カタカナ・末尾の「先生」を区別しない。よみがなを登録した先生は五十音順に並ぶ。件数（例：「2名（全7名）」）、最終更新時刻、「今すぐ更新」を一覧の上に置く。一覧は「名前（よみがな）・教科・PCの場所（推定）・測定時刻」の4列。0件のときは条件をまとめて解除できる。

**掲示用一覧**：職員室前のディスプレイ向け。検索欄を省き、名前と場所を26pxで表示する。日付と時計、最終更新時刻、全画面表示ボタン（全画面中は「全画面を終了」）を置く。研究メモ9.4の「表示範囲を制限する」に合わせ、位置不明の理由などの細かい情報は出さない。

**実験データ**：模擬データとUJIIndoorLocの結果を切り替える。APごとのRSSIの折れ線グラフには、線の端にAP名を直接書き、同じ内容の表（受信回数・平均・範囲）を並べる。色はグラフ用に色覚の違いを考慮して検証した4色を使う（黄と水色は白地でのコントラストが低いため、ラベルと表で補う）。方式別の評価表では、k-NNのkの値とAP選択の有無も表示し、実験BとN、CとGが同じ表示にならないようにした。

**管理（開発用）**：最初にトークン入力だけを表示し、接続してから一覧と操作を出す。トークンはソースに埋め込まず、画面のメモリ内だけに持つ。先生の一覧を先頭に置き、公開/非公開の切り替えと削除（確認ダイアログ付き）を行の中で操作できる。登録・模擬測定・推定方式・APとエリアの対応はその下に並べる。処理中のボタンは`disabled`にせず`aria-disabled`にして、キーボードのフォーカスが失われないようにした。削除の後は「先生の一覧」の見出しにフォーカスを戻す。結果のお知らせ欄は最初から置いておき、読み上げソフトが新しいお知らせを読むようにした。

**共通**：画面を切り替えるとページの題名（ブラウザのタブ名）も「実験データ | 先生のPCエリア案内 | 市川昴高校」のように変わり、キーボードのフォーカスは新しい画面の見出しへ移る。通信が10秒で終わらない場合や、初回の読み込みに失敗した場合も、日本語で状況を表示する。

**スマートフォン（720px以下）**：ヘッダーは校名とメインメニューの2段にし、「実験データ」「管理（開発用）」はフッターへ移した（ヘッダーの高さ149px→97px）。一覧は1人分ずつ、名前・教科・場所を左、測定時刻を右に置く。横スクロールは発生しない。

## コードの構成

画面の部品と表示用の処理を分けている。以下のパスは`frontend/src/`からの相対パスである。

|ファイル|役割|
|---|---|
|`App.tsx`|メニュー、画面の切り替え、一覧の定期取得|
|`views/DirectoryView.tsx`|先生をさがす・掲示用一覧|
|`views/ResearchView.tsx`|実験データ|
|`views/AdminView.tsx`|管理（開発用）|
|`lib/search.ts`|名前・よみがなの検索用の正規化（バックエンドと同じ規則）|
|`lib/teachers.ts`|測定の鮮度判定、理由・方式の表示名|
|`lib/format.ts`|時刻・割合の表示|
|`components/SignalChart.tsx`|RSSIのグラフ|

## 確認すること

名前・よみがな・教科の検索、条件解除、0件、通信失敗（日本語のエラー表示）、期限切れ、非公開、掲示用一覧、管理画面のトークン接続・登録・削除・失敗からの復帰、研究データの切り替えを確認する。実行結果と画像は[確認記録](VERIFICATION.md)に記録する。実際の生徒・教員による利用者テストはまだ行っておらず、今後のPoCで言葉と操作を確かめる。
