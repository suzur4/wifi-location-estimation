# 画面構成と使い勝手の見直し

2026-11-04。利用者の「AIが作ったように見える」という指摘を受け、学校内の案内として日常的に使いやすい構成に変更した。

## 中心になる操作

生徒は、先生の名前または教科から、PCの推定エリアと情報の新しさを短時間で確認する。学校の研究を紹介するランディングページとしては扱わない。

- 上部に校名と用途を短く記す。検索は最初の画面ですぐ使える位置に置く。
- 一覧の主情報を「名前・教科・PC推定エリア・最終測定」とする。繰り返す大きなカードや装飾的なバッジを減らし、複数名を比較しやすくする。
- 名前中の空白、全角半角、末尾の「先生」を検索時に吸収する。結果件数と条件解除を用意し、0件でも操作を続けられるようにする。
- 不明・非公開を短い日本語で区別する。非公開のエリアと測定時刻を隠す。PC検出を先生の在席・面談可否として表現しない。
- ディスプレイ表示では検索フォームを省き、離れて読める名前とエリアの一覧を優先する。
- 研究と管理は副導線にまとめ、生徒の通常操作と競合させない。管理操作の入力・保存・失敗からの復帰は維持する。

## 見た目の判断

生成されたブランド名、英語の飾り見出し、広告のような文句を取り除く。紙の掲示や名簿に近い、暖かい白・濃紺・細い罫線を基調にする。アクセントは必要な操作や識別に限る。外部フォント、イメージ素材、実在しない校舎図は追加しない。

スマートフォンでは行を縦に組み替える。情報の優先順を保ち、横に長い表をそのまま縮めない。状態は色だけに依存せず文字でも示す。キーボードのフォーカスを可視化し、本文への移動で画面が切り替わらないようにする。

## 確認すること

名前・教科検索、条件解除、0件、通信失敗、期限切れ、非公開、一覧表示、管理の入力エラーと復帰、研究結果の表示を確認する。研究用模擬データであること、PCの推定であることを読み取れるようにし、鮮度判定を装飾の変更で失わない。

変更の実行結果と画像は[確認記録](VERIFICATION.md)に記録する。実際の生徒・教員による利用者テストはまだ行っておらず、今後のPoCで言葉と操作を検証する。
