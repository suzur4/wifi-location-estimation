# 表示状態管理を比べる実験

全て模擬データを使う。既存のRSSI生成、k-NN、一次元カルマンと新しいFSMを同じ入力で比較する。教員情報・学校ネットワーク・移動履歴は使わない。

## 再実行

開発環境の依存関係はルートREADMEの手順で導入する。リポジトリ直下から実行する。

```bash
python -m wifi_location.fsm_experiments --output results/fsm
python -m pytest -q
```

Pythonを仮想環境で使う場合は `python` をその仮想環境の実行ファイルに読み替える。新しい未使用シードは `--seeds 41 42 43 --output results/fsm-extra` で指定できる。学習用・調整用と同じシードや重複シードは拒否する。一度結果を見た集合で変更を選んだら、その集合を新しい独立評価とは呼ばない。

## 入力と分離

|用途|固定シード|使い方|
|---|---|---|
|指紋学習|11, 12, 13|各3バッチ×6エリア×16観測。既存生成器で独立生成|
|FSMの調整|21, 22, 23|最終評価と同じ事前定義シナリオで確認回数・スコア差を選択|
|最終評価|31, 32, 33|設定を固定して全方式を実行。シード別結果も保存|

乱数の入力をシードで分離する。架空の端末番号が一致しても、同じ測定値を集合間で共有しない。全て同じ模擬減衰モデルに由来するので、現実環境への一般化を検証したとは扱わない。

各シードの通常評価は18の独立した静止試行、1試行24回・3秒間隔である。加えて、各エリアで以下の独立試行を作る。

|条件|変更|確認したいこと|
|---|---|---|
|一時的な誤指紋|13回目だけ別エリアのRSSIベクトルを入力し、真のエリアは固定|一度の整合した誤判定を表示してしまうか|
|AP欠損|11〜13回目は最大1 AP、14〜16回目は0 AP|過去のRSSIで欠測を埋めず表示を止めるか|
|エリア変更|13回目から別エリアの観測・正解ラベル|候補変更時に以前の場所を表示し続けないか|
|古い観測|12回目の180秒後にGET相当の表示確認。次の測定まで時間を空ける|TTL境界で表示が消え、再確認が必要になるか|
|再送・逆順|12回目の再送と11回目の遅延到着を追加|同じデータで確認回数やカルマンが進まないか|

エリア変更でも処理に正解ラベルを渡さず、FSM・フィルタを人為的に初期化しない。生データで誤りが出なかった試行もそのまま残す。観測を3秒ごとに独立受信する模擬条件であり、実機のキャッシュ更新周期は未検証である。

## 比較条件

|ID|処理|
|---|---|
|A|既存k-NNと既存の信頼性・鮮度判定|
|B|Aの候補がN回続いたときに表示。別候補・位置不明で回数をリセット|
|C|Aの推定をFSMへ入力|
|D|AP別の因果的なカルマン処理後にAと同じ指紋へ照合|
|E|Dの推定をFSMへ入力|

全方式でk=5、既知AP最低2、距離上限16、候補スコア差0.25を固定する。これは現在のWebのk-NN設定に合わせた比較であり、この実験の最終評価で再調整していない。Bも古い観測・再送・逆順を共通の受信処理で扱い、意図的に弱い基準にはしない。BのNはC/Eと同じ選択値。

C/E共通のFSM設定を、N=2,3,4と追加スコア差0.25,0.5の6通りから調整用だけで選ぶ。C/Eを合わせた `正解表示率 − 2 × 誤表示率` を最大化し、同点なら誤表示率、少ないN、小さいスコア差の順で選ぶ。スコアは正解確率ではなくモデル内の相対支持である。Webの初期値は設計上の暫定値として別記し、模擬実験の選択値を本番最適値とはしない。

カルマンは既存の `Kalman1D` を使い、Q=1、R=16、初期分散25。新しい観測だけで更新し、欠測APの状態を消す。独立試行と180秒以上の測定間隔で再初期化する。D/Eも生データで作った共通指紋を使う。この比較では、指紋自体のフィルタ処理やQ/Rの最適化を加えない。Webは最新観測の表示状態だけを管理し、D/Eは独立実験である。

## 指標と分母

- **正解表示率**は鮮度が有効で正しいエリアを表示したイベント数／全評価イベント数。
- **誤表示率**は誤エリア表示または期限切れ表示／全評価イベント数。
- **位置不明率**は場所を表示しなかったイベント数／全評価イベント数。上の3つの合計は100%。
- **表示正答率**は正しく表示したイベント数／場所を表示したイベント数。全件位置不明なら値なし。
- **確定までの観測数・待ち時間**は試行の開始または真のエリア変更から、初めて正しいエリアを表示するまで。再送・逆順を観測数に含めない。到達しなかった区間数を併記し、成功例だけの平均で隠さない。
- **表示変動回数**は隣り合う表示結果の変化。位置不明への切替も含む。独立試行間の変化は除く。
- **期限切れ表示数・一時的な誤表示数**を明記する。条件別の指標も別CSVへ保存する。

GET相当の確認イベントを含むため、全体の比率は純粋な各測定の分類正解率とは異なる。シナリオ別の分母もCSVに保存する。既存EngineにもTTL判定があるため、Aも古い表示を止める。FSMの価値は、候補をすぐ公開しないことと再確認の扱いを合わせて評価する。

## 保存物

`results/fsm/` に全予測CSV、条件別集計CSV、シード別CSV、調整用CSV、2枚のPNG、設定・ソースハッシュ付きJSON、日本語レポートを出力する。実行済みの結果と制約は [FSM_RESULTS.md](FSM_RESULTS.md)、設計は [FSM_DESIGN.md](FSM_DESIGN.md) を参照する。
